# Training history and generalization notes

All charts and notes below are generated from saved per-run JSON results; no historical values are interpolated or fabricated.

## Interpretation limits

- Neural models have one recorded training epoch; convergence and multi-epoch overfitting trends cannot be established.
- Neural training accuracy is in-batch pre-update accuracy, unlike a post-epoch full-training-set evaluation.
- Each held-out test split has 200 class-balanced sampled rows. Test generalization statements are limited to these sampled records.
- Potential overfitting is flagged only when a history has multiple points, training accuracy exceeds validation by at least 0.10, and training loss is below validation loss. Possible underfitting means both endpoint accuracies are below 0.70. These are descriptive heuristics, not statistical tests.
- XGBoost's selected round is its validation-based early-stopping point; it is not proof of global convergence.

## Plot inventory

- One training/validation accuracy and loss plot per model/dataset combination (`*__training.png`). Accuracy uses a shared 0–1 scale; loss uses a shared scale across all runs.
- One test confusion matrix per combination (`*__confusion_matrix.png`), from the saved test predictions.
- Four metric-comparison charts (`model_comparison__*.png`) compare models across datasets on a common 0–1 scale.

Recreate everything with `python ml/plot_training_results.py` after installing `ml/requirements.txt`.
